## 📱 Featured Application: RateSync

**RateSync: Currency Converter** (`com.ratesync.currencyconverter`) provides ultra-fast, offline-first currency conversion, real-time foreign exchange tracking, interactive historical charts, and custom rate alert notifications.

- **Platform Target**: Android 14+ / iOS / Web
- **Monetization**: Google Play In-App Purchases (RevenueCat) & Google Mobile Ads (AdMob)
